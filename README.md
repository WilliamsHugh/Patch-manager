# PatchFlow — Patch Management Portal

Frontend Next.js mô phỏng hệ thống quản lý bản vá, lấy cảm hứng từ bố cục Azure Update Manager. Dự án phục vụ bài cuối kỳ môn Phân tích và Thiết kế Hệ thống Thông tin.

## Khởi chạy

```bash
npm install
npm run dev
```

Mở `http://localhost:3000`.

## Công nghệ

- Next.js 16 (App Router)
- React 19
- TypeScript
- CSS thuần, không phụ thuộc UI framework

Frontend hiện sử dụng dữ liệu mẫu và các tương tác mô phỏng, chưa kết nối API hoặc cơ sở dữ liệu.
